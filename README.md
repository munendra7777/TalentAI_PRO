# TalentAI_PRO

**TalentAI_PRO** is an AI-powered talent profiling and matching system that leverages Large Language Models (LLMs) to analyze candidate profiles, extract key skills, and match them to job opportunities with high accuracy.

## 🚀 Features
- **Multilingual Support** – Processes resumes and job descriptions in Hindi, Indian English, and other languages.
- **LLM Integration** – Uses LangChain and OpenAI APIs for semantic understanding and skill extraction.
- **Custom Scoring Engine** – Ranks candidates based on skill-job fit using NLP similarity metrics.
- **Data Pipeline Automation** – Cleans, normalizes, and structures candidate data for downstream AI models.
- **Extensible Architecture** – Modular design for adding new languages, scoring rules, or AI models.

## 🛠️ Tech Stack
- **Languages**: Python, Bash
- **AI/NLP**: LangChain, Hugging Face Transformers, spaCy
- **Data**: Pandas, NumPy
- **Deployment**: Docker, FastAPI
- **Version Control**: Git
